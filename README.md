# GTNH-Dumper
 Dump data for GTNH wiki

 When KubaTech and Mobs Info are installed, the NEI data dump menu includes an
 `Extreme Entity Crusher Recipes` option. It writes the final EEC recipe map to
 `dumps/eec/eec-runtime.json`; status and failure diagnostics are written beside it.

 Special thanks : https://github.com/GTNewHorizons/ExampleMod1.7.10
